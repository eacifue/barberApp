# Badge

Etiqueta corta de estado de un registro (Activo, Inactivo, Push activo) o de un atributo (Popular, rol).

**Props:** `tone` `'neutral' | 'brass' | 'success' | 'warning' | 'danger' | 'info' | 'oxblood'` · `icon` · `children`.

**Reglas:** una o dos palabras. `oxblood` solo para Popular/Recomendado. Reemplaza el emoji «🔔 Push activo» por `tone='info' icon='bell'`.
