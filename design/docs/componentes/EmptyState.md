# EmptyState

Estado vacío o de error con ícono, título, explicación y siguiente paso.

**Props:** `icon` · `title` · `body` · `action` (un `Button`) o `actionLabel` + `actionIcon` + `actionVariant` + `onAction` · `tone='error'`.

**Textos base:** «Aún no tienes citas» + «Reservar»; «No hay horarios este día» + «Ver otro día»; «No hay barberos para este servicio» + «Elegir otro servicio»; error: «No pudimos cargar …» + «Reintentar».
