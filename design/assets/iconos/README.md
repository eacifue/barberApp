# Iconos

Íconos de tipo de servicio, 24 × 24, trazo 2 px, puntas redondeadas, tinta carbón `#1C1814` (en código se recolorean con el color del token: `brass-ink` sobre `brass-soft`).

- `corte.svg` — Corte (Lucide `scissors`).
- `afeitado.svg` — Afeitado: navaja abierta, propio.
- `barba.svg` — Barba: contorno de barba con bigote, propio.
- `tinte.svg` — Tinte (Lucide `droplets`).
- `tratamiento.svg` — Tratamiento (Lucide `sparkles`).
- `combo.svg` — Combo (Lucide `layers`).
- `otro.svg` — Otro (Lucide `ellipsis`).

El resto de la interfaz usa Lucide completo (lucide-react en web, `lucide_icons_flutter` o estos SVG con `flutter_svg` en móvil). Lucide se distribuye con licencia ISC.
