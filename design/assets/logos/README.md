# Logos

El Portal: arco de fachada + poste de barbero. Colores fijos (no heredan CSS): carbón `#1C1814`, latón `#C6A15B`, granate `#7B2D26`, marfil `#F6F2EA`. El texto de los logos con nombre ya está en curvas (Gloock + Instrument Sans).

- `emblema.svg` — emblema a color para fondos claros (`bg`, `surface`, marfil).
- `emblema-sobre-oscuro.svg` — emblema para fondos oscuros (`carbon`, tema oscuro): arco en filete doble de latón.
- `emblema-mono-tinta.svg` — una sola tinta carbón `#1C1814` (sellos, grabado, impresión a una tinta).
- `emblema-mono-marfil.svg` — una sola tinta marfil `#F4EEE4` sobre fondos oscuros o fotos con panel oscuro.
- `logo-horizontal.svg` / `logo-horizontal-sobre-oscuro.svg` — emblema + BarberShop + MEDELLÍN; sidebar, login, correos.
- `logo-horizontal-mono-tinta.svg` / `logo-horizontal-mono-marfil.svg` — versiones a una tinta.
- `logo-vertical.svg` / `logo-vertical-sobre-oscuro.svg` — apilado para splash, portada y vitrina.
- `app-icon-ios.svg` + `app-icon-ios-1024.png` — ícono iOS (fondo carbón, sin esquinas: iOS aplica la máscara).
- `app-icon-android-foreground.svg` + `app-icon-android-background.svg` + `app-icon-android-monochrome.svg` — ícono adaptativo Android (lienzo 108 dp, contenido en la zona segura de 66 dp; monocromo para íconos temáticos de Android 13+). `app-icon-android-play-512.png` para Google Play.
- `favicon.svg`, `favicon-48.png`, `apple-touch-icon-180.png` — panel web; reemplazan `public/favicon.svg` y `public/logo-mark.svg`.

Mínimos: emblema 16 px de alto (por debajo de 24 px usar `favicon.svg`), horizontal 28 px. Zona de respeto: medio ancho del emblema.
